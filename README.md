# Customer Purchase Prediction Using Machine Learning

## Project Overview

Customer Purchase Prediction is a Machine Learning project developed to predict whether a customer is likely to purchase a product based on demographic information such as Age, Gender and Estimated Salary.

This project follows a complete Data Science workflow including Data Cleaning, Exploratory Data Analysis (EDA), Feature Engineering, Model Development and Prediction using Logistic Regression.

The Logistic Regression algorithm was implemented to classify customers into two categories:

- Purchased (1)
- Not Purchased (0)

The project also identifies potential customers and generates business insights that can help organizations improve their marketing strategies.

---

## Objectives

- Analyze customer demographic data.
- Perform data preprocessing and cleaning.
